# 예리한어학원 회화반 예약 사이트

수강생은 원장님이 등록한 수강권(기간, 횟수)으로 센세와 수업을 골라 예약하고, 센세는 구글 로그인으로 본인 수업의 예약자만 봅니다.
원장님은 전체 예약을 보고, 수강생·수업·센세를 화면에서 등록·수정·삭제합니다. 코드를 고칠 일이 없습니다.

- 수강생: `내주소/`
- 센세·원장: `내주소/staff.html`

## 새 버전으로 바꿀 때 (이미 올린 사이트가 있는 경우)

1. Firebase 콘솔 > Firestore Database > **규칙** 탭에서 기존 내용을 지우고 `firestore.rules` 내용을 붙여넣어 **게시**합니다.
2. Netlify에서 프로젝트 > **Deploys** 탭을 열고 `site` 폴더를 끌어다 놓아 다시 올립니다.
3. `내주소/staff.html` 에 원장님 계정으로 로그인하고 **수업 관리** 탭의 **2026년 11월 시간표로 바꾸기**를 두 번 누릅니다. (처음 설치라면 **기본 시간표 만들기**)
   - 지금 있는 수업이 모두 11월 시간표로 바뀌고, 정원은 수업 길이 규칙(50분 5명 · 70~100분 10명 · 120분 이상 14명)으로 들어갑니다.
   - 바뀌기 전 수업에 이미 들어온 예약은 화면에서 보이지 않게 됩니다. 버튼 위에 그 건수가 표시됩니다.
   - 센세 목록은 그대로 두고, 없는 센세(말랑센세)만 추가됩니다. 말랑센세가 로그인하려면 **센세 관리**에서 구글 이메일을 연결하세요.
4. 다음 달 시간표는 **수업 관리**에서 수업을 직접 고치거나, 저에게 새 시간표를 보내주시면 버튼용으로 만들어 드립니다.
5. **수강생 관리** 탭에서 현재 수강생을 먼저 등록합니다. 등록되지 않은 사람은 예약할 수 없습니다.

## 처음부터 설치할 때

1. Firebase 프로젝트를 만들고 Authentication에서 **익명**과 **Google** 로그인을 켭니다.
2. Firestore Database를 만듭니다 (위치 서울, 프로덕션 모드, Standard 버전).
3. 프로젝트 설정 > 웹 앱을 추가해서 나온 설정값을 `site/firebase-config.js` 에 붙여넣고, `ADMIN_EMAIL` 과 `firestore.rules` 안의 관리자 이메일을 원장님 구글 이메일로 맞춥니다.
4. 규칙을 게시하고, `site` 폴더를 Netlify에 올린 뒤, 그 주소를 Firebase **Authentication > 설정 > 승인된 도메인**에 추가합니다.
5. 위 "새 버전으로 바꿀 때" 3번처럼 기본 시간표를 만듭니다.

## 화면에서 관리하기 (원장님 로그인 후 staff.html)

**센세 관리** 탭
- **센세 추가**: 이름과 구글 이메일을 넣으면 수강생 화면에 센세 이름이 나오고, 그 이메일로 로그인한 센세는 본인 수업만 봅니다. 이메일을 비우면 수강생 화면에만 이름이 나옵니다.
- **센세 로그인 계정 추가**: 한 센세에 이메일을 여러 개 연결할 수 있습니다.
- **이름 변경 / 삭제**: 수업을 맡고 있는 센세는 삭제할 수 없습니다. 먼저 수업을 지우거나 다른 센세로 바꿔주세요.
- **관리자 계정**: 전체 보기 권한이 필요한 사람을 추가합니다.

**수강생 관리** 탭
- **수강생 등록**: 이름, 전화번호 뒤 4자리, 수강 시작일·종료일, 횟수(크레딧)를 넣습니다. 수강생이 입력할 이름과 철자, 띄어쓰기가 같아야 합니다.
- **여러 명 한 번에 등록**: 엑셀이나 구글시트에서 이름 · 뒤 4자리 · 시작일 · 종료일 · 횟수 순서로 복사해서 붙여넣고 **미리보기**를 확인한 뒤 등록합니다. 이미 등록된 사람은 건너뜁니다.
- **수정**: 기간 연장, 남은 횟수와 총 횟수 고치기, **횟수 추가(충전)**. 이름과 번호를 바꾸려면 삭제 후 다시 등록해주세요.
- 수강생이 예약하면 횟수가 차감되고(수업 길이 120분 이상은 2회, 그보다 짧으면 1회), 수업 시작 12시간 전까지 취소하면 차감된 만큼 돌아옵니다.
- 원장님이 예약을 취소할 때는 **횟수 돌려주고 취소** 와 **횟수 차감한 채 취소** 중에서 고릅니다. (12시간 이내 취소는 보통 차감)

**수업 관리** 탭
- 새 수업을 추가할 때 시작·끝 시간을 고르면 수업 길이에 맞는 정원이 자동으로 들어갑니다. (50분 5명 · 70~100분 10명 · 120분 이상 14명, 직접 고칠 수도 있습니다)
- **수업 길이에 맞춰 정원 자동 설정**은 모든 수업의 정원을 위 기준으로 한 번에 바꿉니다.
- **수업별 정원 한 번에 바꾸기**로 같은 이름의 수업 정원을 한꺼번에 바꿀 수도 있습니다.
- 수업명, 담당 센세, 정원, 요일, 시간을 넣어 추가하고, 목록에서 수정·삭제합니다.
- 담당 센세를 바꾸면 이미 들어온 예약도 새 센세 화면으로 같이 옮겨집니다.
- 정원을 줄여도 이미 받은 예약은 그대로 유지됩니다. 수업을 삭제하면 예약 기록은 남지만 화면에서는 보이지 않습니다.

수강생 화면 맨 위에는 수강권 카드(수강 기간, 잔여 일수, 잔여 횟수)가 나옵니다. 처음에 이름과 전화번호 뒤 4자리를 한 번 넣으면 그 기기에 기억됩니다.
정원은 수강생에게 보이지 않고, 자리가 거의 찼을 때(남은 자리 2석 이하)만 "마감 임박 · 잔여 N석"으로 표시됩니다.
수강생 화면은 한 주씩 넘겨 보는 날짜 띠와 수업 카드로 되어 있습니다. 날짜를 누르면 그날 수업이 나오고, 위쪽 **센세 / 시간대 / 수업** 필터와 **마감된 수업도 보기** 스위치로 걸러 볼 수 있습니다. 수업을 하나라도 맡은 센세만 센세 필터에 나옵니다.

## 앱처럼 설치하기 (PWA)

수강생이 사이트 주소를 열고 아이폰은 Safari 공유 버튼 > **홈 화면에 추가**, 안드로이드는 Chrome 메뉴 > **홈 화면에 추가(앱 설치)** 를 누르면 아이콘이 생기고 앱처럼 열립니다. 스토어 등록은 필요 없고, 사이트를 새로 올리면 앱에도 바로 반영됩니다.

## 개인정보 안내와 보관 기간

예약 화면 아래와 예약 입력칸에 수집 항목(이름, 전화번호 뒤 4자리), 목적, 보관 기간(수업일로부터 3개월)이 표시됩니다. 보관 기간을 지키려면 원장님이 staff.html 맨 아래 **3개월 지난 예약 삭제** 버튼을 한 달에 한 번 정도 눌러주세요. 보관 기간을 바꾸려면 안내 문구와 `staff.js` 의 `purgeOld` 를 같이 고쳐야 합니다.

## 처음 확인할 것

- 수강생 화면에서 수강권이 보이고, 예약하면 횟수가 줄고 취소하면 돌아오는지
- 등록하지 않은 이름으로는 예약이 안 되는지, 수강 기간이 지난 날짜는 막히는지
- 수업 시작 12시간 이내 예약은 취소 시 "크레딧 차감" 경고가 나오고, 취소해도 횟수가 돌아오지 않는지
- 정원이 차면 "마감"으로 바뀌는지, 남은 자리가 2석 이하일 때 "마감 임박 · 잔여 N석"이 나오는지
- 수강생 화면에는 이름이 보이지 않고 인원수만 나오는지
- 센세 계정으로 로그인했을 때 본인 수업의 예약자만 보이는지
- 원장님 화면에서 예약 취소와 수업 추가가 되는지

## 알아둘 점

- 수강생 본인 확인은 이름 + 전화번호 뒤 4자리라서, 다른 사람의 이름과 번호를 알면 그 사람 수강권으로 예약할 수 있습니다. 등록된 수강생 목록은 원장님만 볼 수 있습니다.
- 정원은 화면에는 숨겨져 있지만, 기술을 아는 사람이 개발자 도구로 시간표 데이터를 열어보면 알 수 있습니다.
- 12시간 이내 취소 시 환불 제한과 회차 차감은 Firebase 보안 규칙에도 들어 있습니다. 이 규칙은 시험용 환경에서 실행해보지 못했으니, 새로 올린 뒤 꼭 실제로 예약과 취소를 해보세요.
- 수강생이 직접 취소하려면 예약한 기기와 브라우저에서 열어야 합니다. 다른 기기에서는 원장님 화면에서 취소해주세요.
- 보관 기간은 수업일·수강 종료일로부터 3개월입니다. 원장님 화면 맨 아래 **3개월 지난 예약 삭제** 버튼이 예약과 기간이 끝난 수강생 정보를 같이 지웁니다.
- 전화번호 뒤 4자리는 센세·원장 화면에서만 보입니다.
- Firebase 무료 요금제(Spark)가 아니라 Blaze 요금제입니다. 무료 사용량 안에서는 청구되지 않고, Google Cloud 콘솔에서 예산 알림을 걸어두세요.


## 매월 20일 오픈 / 달이 바뀔 때 시간표 고치기
- 수강생은 매월 20일 0시(한국시간)부터 다음 달 수업을 예약할 수 있습니다. 다음 달 1~4일은 이번 달 시간표의 연장이라 항상 열려 있고, 다음 달 5일부터는 20일 전까지 "아직 오픈되지 않은 시간표입니다"가 보입니다. (보안 규칙에서도 같은 기준으로 막습니다.)
- 시간표가 달 단위로 바뀌는 수업은 **수업 관리 → 수정**에서 "적용 시작일/종료일"을 씁니다. 예) 12월부터 시간이 바뀌는 수업: 기존 수업의 적용 종료일을 11월 30일로 하고, 새 시간으로 같은 수업을 하나 더 추가하면서 적용 시작일을 12월 1일로 합니다. 이렇게 하면 20일에 미리 고쳐도 11월 남은 수업은 그대로입니다.

## 다른 기기에서도 내 예약 보기/취소
- 이름과 전화번호 뒤 4자리로 수강권을 확인하면, 어느 기기에서든 내 예약이 보이고 언제든 취소할 수 있고, 12시간 이내 취소는 크레딧이 차감됩니다.

## 관리자 페이지 (업데이트 관리용)
- **예약 현황**: 월 달력에 날짜별 예약자 수가 보이고, 센세를 누르면 그 센세 기준으로 달력과 월 합계가 바뀝니다. 날짜를 누르면 오른쪽(PC) 또는 아래(모바일)에 그날 수업과 예약자가 나옵니다.
- **수강생 관리 → 수납장부·신청내역 엑셀로 수강생 업데이트**: .xlsx/.csv 를 올리면 이름·상품·기간·횟수를 읽어 지금 수강생과 비교한 미리보기를 보여주고, "반영"을 누를 때만 저장합니다. (신규 등록 / 기간·총횟수 맞춤(사용한 횟수 유지) / 새 수강권으로 교체 / 횟수 추가 / 건너뜀 중 고르기)
- **수업 관리 → 새 시간표 파일로 업데이트**: 엑셀·CSV 또는 붙여넣은 글을 읽어 현재 시간표와 비교합니다. 기존 수업은 지우지 않고 "적용 종료일"만 넣고, 새 수업은 "적용 시작일"과 함께 추가하므로 지난 예약과 이번 달 수업이 그대로 남습니다. 바꾸기 직전 시간표는 자동 백업되고 "되돌리기" 버튼이 있습니다. 종료된 지 3개월이 지난 수업은 "지난 예약 정리"에서 같이 정리됩니다.
- 사진·PDF 는 서버 함수(functions 폴더)가 AI로 읽어 표로 바꿔줍니다. 켜는 방법은 DEPLOY.md 의 "사진·PDF 읽기 켜기". 읽은 결과는 항상 미리보기에서 확인한 뒤에만 반영됩니다.

## 이날의 수업 주제
- 담당 센세(본인 수업)와 관리자가 예약 현황 → 날짜 → 수업 칸의 "이날의 주제"에 최대 60자까지 입력·저장합니다. 비우고 저장하면 삭제됩니다.
- 학생 화면의 수업 카드에 "이날의 주제"로 보입니다. Firestore `topics/{날짜_수업}` 문서, 규칙은 `firestore.rules`의 `topics` 항목.
